Puce de filtre en pilule, 52 px. Sélectionnée : fond pêche et coche. Non sélectionnée : blanc bordé pêche ; en mode `categorie`, le pictogramme est en terre cuite.

```jsx
<PuceFiltre selectionnee>Toutes</PuceFiltre>
<PuceFiltre categorie icone="celebration">Moments partagés</PuceFiltre>
<PuceFiltre icone="history">Passées</PuceFiltre>
```
