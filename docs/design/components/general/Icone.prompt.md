Pictogramme Material Symbols Rounded, toujours décoratif : un texte l'accompagne.

```jsx
<Icone nom="location_on" couleur="var(--color-on-surface-variant)" />
<Icone nom="home" plein taille={26} />
```

Tailles en usage : 20 (badge), 22 (puce sélectionnée, pastille catégorie), 24 (défaut), 26 (panneau d'infos, barre de navigation, stepper), 28 (Retour, logo, bouton flottant).
